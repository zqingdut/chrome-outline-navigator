Page Outline Navigator：智能页面大纲导航插件

这是一个 Chrome 浏览器插件，能够自动识别网页中的标题结构，在右侧生成可交互的导航大纲。支持通用网页和热门问答网站的精准适配。

核心功能

插件的核心能力是自动解析页面结构，生成可视化的导航大纲，帮助用户快速定位和跳转到感兴趣的内容区域。

自动标题识别

插件会自动扫描页面中的 h1-h6 标题标签，构建层级化的目录结构。支持所有标准 HTML 页面，无需额外配置。

热门网站适配

针对知乎、Stack Overflow、CSDN、掘金、SegmentFault、简书、Medium、GitHub 等热门网站，使用专用的选择器进行精准的内容提取。

知乎适配

自动识别问题标题和各个回答中的小标题，生成问答结构化大纲。

Stack Overflow 适配

提取问题和回答中的代码块标题、步骤说明等结构化内容。

实时高亮追踪

随着页面滚动，侧边栏会自动高亮当前可见区域对应的标题，帮助用户了解自己在文档中的位置。

交互设计

交互设计参考了 aihot.virxact.com 的深色主题风格，采用现代感十足的暗色系配色方案。

深色主题

整体采用深蓝黑渐变背景，配合柔和的蓝绿色系高亮，视觉舒适不刺眼。标题层级通过不同颜色的圆点标记来区分。

搜索过滤

内置搜索框支持实时过滤标题内容，当页面标题较多时可以快速定位到目标章节。

快捷键支持

按下 Alt + O 即可快速切换侧边栏的显示和隐藏状态，不影响正常浏览体验。

技术实现

基于 Chrome Extension Manifest V3 规范开发，使用 Content Script 注入页面，轻量无侵入。

DOM 解析策略

优先使用站点专用选择器，通用回退到 h1-h6 标签。对 SPA 应用支持 MutationObserver 监听 DOM 变化，自动更新大纲。

性能优化

滚动高亮使用防抖机制（100ms），避免频繁计算。侧边栏使用 CSS 硬件加速动画，流畅不卡顿。

使用方法

安装后无需任何配置，打开任意包含标题结构的网页即可自动激活。

安装步骤

1. 打开 Chrome 扩展管理页面 chrome://extensions/
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择插件目录即可

适用场景

适用于技术文档、博客文章、问答页面、API 文档等任何具有标题结构的网页内容。
