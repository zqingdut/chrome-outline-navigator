常见技术问题 FAQ

Q：什么是 REST API？
A：REST API 是一种基于 HTTP 协议的接口设计风格，使用标准的 GET/POST/PUT/DELETE 方法来操作资源。
Q：Git 和 SVN 有什么区别？
A：Git 是分布式版本控制系统，每个开发者都有完整的仓库副本；SVN 是集中式版本控制系统，依赖中央服务器。
Q：什么是 Docker？
A：Docker 是一个容器化平台，可以将应用及其依赖打包成标准化的容器，实现"一次构建，到处运行"。
Q：前端框架 React 和 Vue 怎么选？
A：React 生态更大，适合大型项目和团队；Vue 学习曲线更平缓，适合中小型项目和个人开发。
Q：什么是微服务架构？
A：微服务是将大型应用拆分为多个小型、独立部署的服务，每个服务负责一个特定的业务功能，通过 API 通信。
